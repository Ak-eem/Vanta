# VANTA Eyes (Chrome extension)
1. Chrome → `chrome://extensions` → turn on Developer mode → **Load unpacked** → pick this folder.
2. Open the extension's Options and paste your VANTA access token.
Reads visible text only (never password/input fields), skips incognito (Chrome default), sends to `127.0.0.1` only. VANTA's privacy blocklist and pause apply on the server side too.
