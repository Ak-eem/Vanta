# VANTA UI designs

Place incoming interface designs in this folder:

- Use `.tsx` for React components and screens.
- Use `.ts` for TypeScript helpers and design data.
- Keep shared app-wide styles in `../styles.css`; component-specific styles can live alongside their `.tsx` file.
- `BorderGlow.tsx` is a reusable pointer-reactive card component, and `BorderGlowPreview.tsx` shows its VANTA-themed sample usage at `/?design=border-glow`.

The existing VANTA UI is React with TypeScript, built by Vite.
